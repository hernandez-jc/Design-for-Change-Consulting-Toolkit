## Maturity scale

| Rating | Level | Description |
|---:|---|---|
| 1 | Initial | The area is unclear, inconsistent, or not actively managed. |
| 2 | Developing | Some practices exist, but they are incomplete or inconsistently applied. |
| 3 | Defined | Basic practices are defined and used in most relevant areas. |
| 4 | Managed | Practices are consistent, monitored, and supported by clear ownership. |
| 5 | Optimized | Practices are effective, reviewed regularly, and adapted as needs change. |

## Action types

| Action type | Meaning |
|---|---|
| Quick win | A practical improvement that can be started or completed within the 10-day roadmap. |
| Foundational | An important improvement that supports adaptability, quality, or governance but may require more coordination. |
| Deferred | A valid issue that should be addressed in a later improvement cycle. |
| Out of scope | An issue that requires a separate project, decision, budget, or specialist input. |
