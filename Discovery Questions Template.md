# Discovery Questions Template

Use this template to collect focused input from stakeholders before completing the Learning Checkup Scorecard.

Save the completed version as:

```text
discovery-questions.md
```

This template supports the eight assessment areas defined in the project charter:

1. Strategy and business alignment  
2. Learners and audiences  
3. Content and learning design  
4. Administration and usability  
5. Data and reporting  
6. Accessibility and inclusion  
7. Integrations and interoperability  
8. Governance and change readiness  

Use only the questions relevant to each stakeholder. The goal is to gather enough evidence to identify practical priorities for a 10-day improvement roadmap.
