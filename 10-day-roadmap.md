## Roadmap stages

| Stage | Days | Purpose |
|---|---|---|
| Prepare and confirm | 1–2 | Confirm actions, owners, access, dependencies, and success measures. |
| Deliver improvements | 3–8 | Complete selected quick wins and begin scoped foundational improvements. |
| Review and communicate | 9–10 | Review results, communicate changes, and document next steps. |

## Field guidance

| Field | What to enter |
|---|---|
| **Action ID** | A unique identifier, such as `A-01`, `A-02`, or `A-03`. |
| **Related priority ID** | The priority ID from `prioritization-matrix.csv`, such as `P-01`. |
| **Related barrier ID** | The barrier ID from `barriers-log.csv`, such as `B-01`. |
| **Assessment area** | The area from the Learning Checkup Scorecard. |
| **Action** | A short, practical description of the improvement. |
| **Action stage** | Prepare and confirm, Deliver improvements, or Review and communicate. |
| **Owner** | The person or role accountable for completing the action. |
| **Deliverable** | The specific output that will demonstrate completion. |
| **Start day** | The planned start day, from 1 to 10. |
| **End day** | The planned completion day, from 1 to 10. |
| **Dependencies** | People, systems, approvals, or events required before the action can proceed. |
| **Required access or approval** | Moodle access, report access, content approval, stakeholder approval, or other requirement. |
| **Success measure** | A simple way to confirm whether the action achieved its intended purpose. |
| **Status** | Not started, In progress, Complete, Deferred, or Cancelled. |
| **Result or evidence** | The observed result, feedback, report, or evidence of completion. |
| **Next step** | The follow-up action, if any. |
| **Notes** | Additional context, assumptions, blockers, or decisions. |

## Completion checklist

Before closing the 10-day cycle, confirm that:

- [ ] Each action is linked to a priority and barrier.
- [ ] Each action has one accountable owner.
- [ ] Each action has a defined deliverable.
- [ ] Dependencies and required approvals are recorded.
- [ ] Start and end days fit within the 10-working-day period.
- [ ] Each action has a simple success measure.
- [ ] Status and evidence are updated during the cycle.
- [ ] Deferred or incomplete actions have a documented next step.
